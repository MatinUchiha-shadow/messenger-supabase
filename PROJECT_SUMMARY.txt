## ۵. ساختار دیتابیس (Supabase)
# -----------------------------

### جدول profiles:
- id: UUID (primary key, references auth.users)
- username: TEXT (unique)
- display_name: TEXT
- role: TEXT ('owner', 'admin', 'user')
- avatar_url: TEXT
- bio: TEXT (بیوگرافی)
- created_at: TIMESTAMPTZ

### جدول rooms:
- id: UUID (primary key)
- name: TEXT
- type: TEXT ('text', 'voice')
- created_by: UUID (references profiles)
- created_at: TIMESTAMPTZ

### جدول messages:
- id: UUID (primary key)
- room_id: UUID (references rooms)
- user_id: UUID (references profiles)
- type: TEXT ('text', 'image', 'voice', 'file', 'video')
- content: TEXT
- file_url: TEXT
- file_name: TEXT
- file_size: BIGINT
- reply_to_id: UUID
- reply_to_name: TEXT
- reply_to_text: TEXT
- created_at: TIMESTAMPTZ

### Storage Buckets:
- avatars (public) - آواتار کاربران
- uploads (public) - فایل‌های عمومی
- chat-images (public) - تصاویر چت
- chat-videos (public) - ویدیوهای چت

### RLS Policies:
- profiles: هر کسی می‌تواند بخواند، فقط خودش ویرایش کند
- rooms: هر کسی می‌تواند بخواند، authenticated می‌تواند ایجاد کند
- messages: هر کسی می‌تواند بخواند، فقط خودش پیام ارسال کند
- storage: authenticated می‌تواند آپلود/دانلود کند

## ۶. امکانات پیاده‌سازی شده
# ==========================

### ۶.۱ احراز هویت (Auth):
- ثبت‌نام با ایمیل و رمز عبور
- ورود با ایمیل و رمز عبور
- خروج از حساب
- اولین کاربر = owner (مالک)
- نمایش نقش کاربر (owner/admin/user)

### ۶.۲ سایدبار:
- نمایش اتاق‌های متنی
- نمایش اتاق‌های صوتی
- نمایش لیست پیام‌های خصوصی (DM)
- نمایش کاربران آنلاین (Presence)
- دکمه ایجاد اتاق جدید (فقط owner/admin)
- دکمه تم
- دکمه خروج
- منوی موبایل (hamburger)

### ۶.۳ اتاق‌ها:
- اتاق‌های متنی (گروهی)
- اتاق‌های صوتی
- ایجاد اتاق جدید توسط owner/admin
- انتخاب اتاق از سایدبار

### ۶.۴ پیام‌رسانی متنی:
- ارسال پیام متنی
- نمایش پیام‌ها با آواتار کاربر
- نمایش نام فرستنده
- نمایش زمان ارسال
- نمایش تیک تحویل (read receipt)
- پیام‌های خودم = سمت چپ (RTL)
- پیام‌های دیگران = سمت راست
- انیمیشن slideUp برای پیام‌های جدید
- اسکرول خودکار به آخرین پیام

### ۶.۵ پیام‌های خصوصی (DM):
- لیست کاربران برای شروع چت خصوصی
- جستجوی کاربران
- اتاق DM خودکار با نام [userId1, userId2].sort().join('_')
- جدا از اتاق‌های گروهی

### ۶.۶ ریپلای (Reply):
- ریپلای به پیام خاص
- نمایش نام فرستنده اصلی
- نمایش متن پیام اصلی (حداکثر 50 کاراکتر)
- نوار ریپلای بالای اینپوت
- دکمه لغو ریپلای

### ۶.۷ ری‌اکشن (Reactions):
- 6 ری‌اکشن: 👍 ❤️ 😂 😮 😢 🔥
- انتخاب ری‌اکشن از منوی راست‌کلیک
- نمایش تعداد ری‌اکشن‌ها
- تغییر وضعیت ری‌اکشن با کلیک
- نمایش ری‌اکشن‌های خودم با رنگ متفاوت

### ۶.۸ منوی پیام (Context Menu):
- کلیک راست / long press روی پیام
- گزینه‌ها: ری‌اکشن، ریپلای، کپی، حذف (فقط پیام خودم)
- موقعیت خودکار منو

### ۶.۹ آپلود مدیا:
- آپلود تصویر (از گالری یا دوربین)
- آپلود ویدیو
- پیش‌نمایش قبل از ارسال
- نوار پیشرفت آپلود
- حداکثر حجم: 50MB
- storage buckets جداگانه برای تصاویر و ویدیوها
- پاکسازی خودکار فایل‌های قدیمی (بیش از 3 ساعت)

### ۶.۱۰ نوار ایموجی:
- 30 ایمیج محبوب
- نوار افقی قابل اسکرول
- کلیک روی ایموجی = اضافه شدن به اینپوت

### ۶.۱۱ چت صوتی (Voice Chat):
- ورود به اتاق صوتی
- WebRTC برای ارتباط همتا به همتا
- STUN servers: Google
- نمایش اعضا در call panel
- قطع و وصل میکروفون (mute/unmute)
- نمایش وضعیت میکروفون هر کاربر
- تایمر مدت تماس
- خروج از تماس

### ۶.۱۲ اشتراک‌گذاری صفحه (Screen Share):
- اشتراک‌گذاری صفحه در حین تماس صوتی
- نمایش صفحه اشتراکی در tile بزرگ
- ارسال ویدیو به همه peers
- renegotiation خودکار WebRTC
- توقف اشتراک‌گذاری
- حالت تمام‌صفحه برای مشاهده صفحه اشتراکی

### ۶.۱۳ پنل تماس (Meet-like Call Panel):
- طراحی شبیه Google Meet
- نمایش grid از شرکت‌کنندگان
- هر tile شامل: آواتار، نام، وضعیت میکروفون
- نشان‌گر speaking (سبز)
- دکمه‌ها: میکروفون، اشتراک صفحه، تمام‌صفحه، پایان
- ریسپانسیو برای موبایل

### ۶.۱۴ پروفایل کاربر:
- نمایش آواتار
- نمایش نام نمایشی
- نمایش ایمیل
- نمایش نقش (owner/admin/user)
- نمایش تعداد پیام‌ها
- نمایش تاریخ عضویت
- ویرایش نام (فقط خودم)
- ویرایش بیو (فقط خودم)
- آپلود آواتار (فقط خودم)
- مودال پروفایل با انیمیشن

### ۶.۱۵ سیستم تم (Theme):
- 5 تم پیش‌فرض:
  1. پیش‌فرض (تاریک بنفش)
  2. سیاه‌چاله (Black Hole) - با SVG متحرک
  3. اقیانوسی (آبی)
  4. بنفش شب
  5. روشن (سفید)
- ذخیره تم در localStorage
- CSS Variables برای تغییر رنگ‌ها
- انیمیشن‌های مخصوص هر تم
- Black Hole: accretion disk متحرک، gravitational lensing، hotspots

### ۶.۱۶ ریسپانسیو (Responsive):
- موبایل: سایدبار overlay
- hamburger menu
- اندازه فونت بزرگ‌تر برای موبایل
- touch-friendly
- fix برای کیبورد موبایل (Android)

### ۶.۱۷ اعلان‌ها (Toast):
- پیام‌های کوتاه در پایین صفحه
- انیمیشن fade in/out
- حذف خودکار بعد از 2.2 ثانیه

## ۷. انیمیشن‌ها و افکت‌ها

## ۸. نکات فنی مهم
# ================

### Supabase CDN:
- آدرس: https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2
- متغیر سراسری: supabase
- نباید دوباره تعریف شود (از db استفاده شده)

### Supabase Key Format:
- کلید جدید (sb_publishable_...) سازگار نیست
- باید از Legacy JWT key استفاده شود
- فرمت: eyJhbGciOiJIUzI1NiIs...

### Realtime Subscriptions:
- postgres_changes برای پیام‌های جدید
- presence برای وضعیت آنلاین
- broadcast برای WebRTC signaling

### WebRTC:
- STUN only (بدون TURN)
- Google STUN servers
- Renegotiation برای screen share

### Storage Auto-cleanup:
- فایل‌های chat-images و chat-videos بعد از 3 ساعت پاک می‌شوند
- آواتارها پاک نمی‌شوند
- هر 5 دقیقه بررسی می‌شود
